# Governança de Dados — Base de Conhecimento

Bem-vindo ao seu espaço estruturado de estudos e referências sobre **Governança de Dados**.

A organização dos módulos combina os fundamentos do **DAMA-DMBOK** com práticas modernas de engenharia e gestão de dados (observabilidade, *Data Contracts*, catálogos modernos, *Lakehouse* e *Data Mesh*).

## Mapa dos Módulos

| Módulo | Foco Principal |
| --- | --- |
| **01. Fundamentos** | Conceitos essenciais, DAMA-DMBOK, estratégia e maturidade |
| **02. Papéis e Estrutura** | Data Owner, Data Steward, comitês, modelos operacionais e políticas |
| **03. Qualidade de Dados** | Dimensões, métricas, SLAs, observabilidade e *Data Contracts* |
| **04. Catálogo, Metadados e Linhagem** | Metadados, catálogo de dados, glossário de negócios e *Data Lineage* |
| **05. Segurança, Privacidade e LGPD** | Classificação, controle de acesso, conformidade e auditoria |
| **06. Arquitetura e Ciclo de Vida** | Ciclo de vida, MDM, dados de referência e arquiteturas modernas |
| **07. Ferramentas e Ecossistema** | Comparativos e anotações de ferramentas de catálogo e qualidade |
| **08. Casos Práticos e Estudos** | Estudos de caso reais e checklist de implantação |

## Como usar esta base

1. **Preencha no seu ritmo:** cada página já traz a estrutura padrão e tópicos-guia para orientar seus estudos.
2. **Crie novas notas rapidamente:** copie o arquivo [Modelo de Nota (Template)](./modelo-de-nota.mdx) para dentro da pasta do módulo desejado — a sidebar é atualizada automaticamente.
3. **Use tags e links internos:** conecte assuntos relacionados (por exemplo, ligando *Data Contracts* a *Qualidade de Dados* e *Papéis*) para transformar suas anotações em uma rede de conhecimento.
