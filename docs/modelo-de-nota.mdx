# Modelo de Nota (Template)

Use esta página como ponto de partida sempre que quiser adicionar um novo assunto à base de conhecimento.

:::tip Como criar uma nova nota
Duplique o arquivo `docs/modelo-de-nota.mdx` para a pasta do módulo correspondente (ex.: `docs/01-fundamentos/meu-novo-tema.mdx`), ajuste o cabeçalho (*frontmatter*) e preencha as seções abaixo.
:::

---
